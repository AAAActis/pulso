Arquitectura y Seguridad

Resiliencia

HybridCache (L1 + L2): Memoria in-proceso (TTL 15s) + Redis compartido (TTL 60s, prefijo pulso:). Si Redis no está disponible, la app opera solo con L1 sin errores.

Polly v8 (HTTP Resilience): Timeout 3s, Retry 1× con jitter 200ms, Circuit Breaker que protege al servidor tras fallos consecutivos.

Monitoreo Doble Vía

Cada servicio se verifica por dos rutas independientes:

  • Red Interna (Docker): Red privada de contenedores, URLs internas (http://container:port)
  • URL Pública (Cloudflare): Túneles Cloudflare públicos

Estados resultantes: ONLINE/UP · FALLO DE TÚNEL · DESCONECTADO

Seguridad

CORS estricto: Solo https://s-portfolio.bbasolutions.ar (y localhost en Development).

Rate Limiting: 5 req/min en /lab/simulate-failure, 60 req/min global. Lee CF-Connecting-IP para IP real detrás de Cloudflare.

Headers: CSP, X-Content-Type-Options: nosniff, Referrer-Policy, Permissions-Policy. Errores en formato ProblemDetails (RFC 9457).

Endpoints

  • GET /api/v1/summary — KPIs globales (con ETag / 304)
  • GET /api/v1/services — 5 servicios + datos de laboratorio
  • GET /api/v1/stream — SSE cada 3s + push inmediato en simulación
  • POST /api/v1/lab/simulate-failure — Activa simulación 45s
  • GET /health/live · GET /health/ready
